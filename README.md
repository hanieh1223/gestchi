# قسط‌یار (Gestchi)

پروژه رابط کاربری سامانه قسط‌یار با React و Vite.

## فناوری‌ها
- React 19
- Vite 7
- React Router
- CSS ماژولار مبتنی بر design tokens
- ESLint و Prettier

## راه‌اندازی
نسخه Node.js موردنیاز Vite را نصب کنید، سپس:

```bash
npm install
npm run dev
```

برای بررسی تولید:
```bash
npm run lint
npm run build
npm run preview
```

## ساختار کد
- `src/app`: نقطه ورود برنامه و تعریف مسیرها
- `src/features`: قابلیت‌ها و صفحات مستقل محصول
- `src/components/shared`: اجزای مشترک رابط
- `src/layouts`: چیدمان‌های سطح برنامه
- `src/data`: داده‌های نمایشی فعلی
- `src/services`: محل پیاده‌سازی ارتباط با API
- `src/hooks`: هوک‌های اشتراکی
- `src/utils`: توابع کمکی بدون وابستگی به UI
- `src/styles`: توکن‌ها، استایل‌های پایه و استایل اپلیکیشن

## وضعیت مهاجرت
نسخه اولیه React شامل پوسته اصلی، صفحه خانه، فهرست فروشگاه‌ها و فهرست محصولات است. داده‌های موجود در `src/data/demoData.js` نمونه هستند و هنوز به API یا پایگاه داده متصل نیستند.

فایل HTML اولیه به‌عنوان مرجع رفتاری و بصری مهاجرت استفاده می‌شود. قابلیت‌های پیچیده مانند محاسبه اقساط، سبد خرید، احراز هویت، ثبت سفارش، استعلام‌ها و پنل فروشنده باید به‌صورت مرحله‌ای و با تست مستقل منتقل شوند؛ این بخش‌ها هنوز در نسخه React پیاده‌سازی نشده‌اند.
